# 🚀 GafBazJavaFX (кликер)

Стильный кроссплатформенный кликер, построенный на базе **JavaFX** и веб-технологий, с нативным скрытым лаунчером на **C++** и автоматической системой сборки дистрибутива.

---

## 🛠️ Технологический стек

| Компонент | Технология | Описание |
| :--- | :--- | :--- |
| **Интерфейс** | HTML5 / CSS3 / JavaScript | Адаптивный UI, работающий внутри изолированного WebView |
| **Ядро игры** | Java 25 / JavaFX 25 | Обработка логики кликов, управление модулями и мост с JS |
| **История** | Google Gson 2.11.0 | Хранение сессий в красивом формате JSON на жестком диске |
| **Лаунчер** | C++ (MSVC / WinAPI) | Нативный стартер: распаковывает библиотеки и тихо запускает игру |
| **Установщик**| Inno Setup | Мультиязычный инсталлятор, работающий без прав администратора |

---

## ⚙️ Как это устроено (Архитектура)

Проект спроектирован по принципу модульных игровых лаунчеров (в стиле Minecraft):
1. Пользователь запускает нативный файл `clicker.exe` (написан на **C++**).
2. Лаунчер скрытно и быстро распаковывает встроенные зависимости и модули JavaFX во временный системный каталог `%TEMP%\GBJFX`.
3. Лаунчер автоматически находит Java в системе (проверяя популярные пути Eclipse Adoptium, Oracle JDK или переменную `%PATH%`) и запускает изолированный процесс виртуальной машины без лишних окон.
4. Игра использует **JavaScript-мост (JSObject)** для бесшовной передачи данных между веб-интерфейсом в WebView и бэкендом на Java.
5. История кликов с кодировкой UTF-8 пишется во внешний файл `assets/clicks/clicks.json` и автоматически подгружается при старте.
